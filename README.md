# Billing System

A simple console-based billing system written in C. It lets users select products and quantities, calculates a discount based on the bill amount, adds 18% GST, and displays the final bill.

## Features

- Product list with prices
- Add multiple products and quantities
- Automatic discount based on total purchase
- GST calculation
- Final bill summary

## Products

- Laptop — Rs. 50,000
- Mouse — Rs. 500
- Keyboard — Rs. 1,000
- Printer — Rs. 8,000
- Pen Drive — Rs. 700
